## Informations du projet

- **Nom** : Initiation à Pandas
- **Date** : 2024
- **Contexte** : Projet d'initiation à la manipulation de données avec Pandas
- **Description** : Ce projet est une introduction aux fonctions de Pandas pour analyser et manipuler des données dans un DataFrame.

## Description du projet

Ce projet vise à explorer les bases de Pandas, une bibliothèque Python populaire pour la manipulation et l'analyse de données. À travers ce projet, vous apprendrez à :

1. Charger un fichier CSV dans un DataFrame Pandas.
2. Utiliser des fonctions comme `mean()`, `sum()`, `min()`, `max()` pour effectuer des calculs sur les données.
3. Manipuler et nettoyer les données (filtrage, suppression de doublons, etc.).
4. Sauvegarder les résultats de l'analyse dans un nouveau fichier CSV.

## Fonctionnalités

- **Chargement d'un fichier CSV** : Charger les données d'un fichier CSV dans un DataFrame Pandas.
- **Calculs statistiques** : Calcul de la moyenne, de la somme, du minimum, du maximum et d'autres statistiques sur les données numériques d'un DataFrame.
- **Manipulation des données** : Suppression des doublons, filtrage des lignes selon des conditions spécifiques, et ajout de nouvelles colonnes calculées.
- **Sauvegarde dans un nouveau CSV** : Sauvegarder les données traitées et les résultats dans un fichier CSV.

## Prérequis

- **Python** (version 3.7 ou supérieure)
- **Pandas** : Pour la manipulation de données.
- **Matplotlib** (optionnel) : Pour la visualisation des données (si nécessaire).

## Installation

1. Clonez le projet ou téléchargez les fichiers nécessaires.
2. Créez un environnement virtuel (optionnel) et installez les dépendances :
    ```bash
    pip install pandas matplotlib
    ```
3. Assurez-vous d'avoir un fichier CSV avec des données que vous souhaitez analyser.

## Comment utiliser le projet

1. Ouvrez le script Python qui contient le code.
2. Assurez-vous que le fichier CSV est bien placé dans le répertoire du projet ou mettez à jour le chemin dans le code.
3. Exécutez le script pour charger les données, effectuer les calculs, et manipuler les données à l'aide des fonctions Pandas.
4. Le script génère un nouveau fichier CSV contenant les données manipulées ou traitées.
5. Vous pouvez adapter le code pour effectuer d'autres analyses sur différents jeux de données.
